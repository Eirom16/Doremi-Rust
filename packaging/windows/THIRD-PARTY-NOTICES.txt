==========================================================
Doremi itself: GNU General Public License v3.0 (see LICENSE.txt,
installed alongside this file as {app}\LICENSE.txt).

This bundle redistributes third-party binaries. This file lists them,
their licenses as published by their owners, and what remains to fully
satisfy redistribution obligations. It is NOT legal advice. A public
release stays BLOCKED until the items marked BLOCKED below are closed.

How versions are pinned
-----------------------
- Python packages: resolved at build time by pip on the CI runner
  (Windows, Python 3.12). The exact resolved set is captured per build
  (`pip freeze` + VLC version, see CI log / installer-manifest.txt
  artifact). Constraints at F0B-2B (pyproject.toml):
    PySide6>=6.7.0, qasync, qt-material, ytmusicapi, yt-dlp>=2026.8.19,
    python-vlc, SQLAlchemy+aiosqlite, alembic, pydantic, tomli-w,
    httpx[http2], syncedlyrics, pystray, pillow, loguru, keyring.
- Rust extension: exact versions in src/doremi/native_rs/Cargo.lock
  (committed): doremi-native-rs 0.1.0, pyo3 0.23.5, aho-corasick 1.1.4,
  memchr 2.8.2, libc 0.2.186, once_cell 1.21.4, portable-atomic 1.13.1,
  + build-time transitive deps (proc-macro2, quote, syn, unicode-ident,
  autocfg, cfg-if, heck, indoc, unindent, memoffset, pyo3-build-config,
  pyo3-ffi, pyo3-macros, pyo3-macros-backend, rustversion,
  target-lexicon). All are MIT and/or Apache-2.0 (crates.io metadata).
- VLC: installed on CI via `choco install vlc`, then libvlc.dll,
  libvlccore.dll and the full plugins/ tree are copied into
  vlc_libs/ and collected by PyInstaller (doremi.spec). The concrete
  VLC version varies with Chocolatey at build time and is recorded in
  the CI log (`vlc --version` / choco info). No VLC version is vendored
  in git.
