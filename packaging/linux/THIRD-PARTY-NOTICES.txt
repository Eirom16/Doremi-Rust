DOREMI — THIRD-PARTY NOTICES (F0B-3A, Linux x86_64 portable)
=============================================================
Doremi itself: GNU General Public License v3.0 (see LICENSE.txt,
shipped alongside this file).

This bundle redistributes third-party binaries. This file lists them,
their licenses as published by their owners, and what remains to fully
satisfy redistribution obligations. It is NOT legal advice. A public
release stays BLOCKED until the items marked BLOCKED below are closed.

How versions are pinned
-----------------------
- Python packages: resolved at build time by pip on the CI runner
  (Ubuntu 22.04, Python 3.12). The exact resolved set is captured per build
  (`pip freeze` + VLC/dpkg versions, see CI log / linux-manifest.txt
  artifact). Constraints at F0B-3A (pyproject.toml):
    PySide6>=6.7.0, qasync, qt-material, ytmusicapi, yt-dlp>=2026.8.19,
    python-vlc, SQLAlchemy+aiosqlite, alembic, pydantic, tomli-w,
    httpx[http2], syncedlyrics, pystray, pillow, loguru, dbus-python (Linux),
    keyring.
- Rust extension: exact versions in src/doremi/native_rs/Cargo.lock
  (committed): doremi-native-rs 0.1.0, pyo3 0.23, aho-corasick 1.x
  (+ transitive crates.io deps). All are MIT and/or Apache-2.0
  (crates.io metadata).
- VLC: installed on CI via `apt-get install vlc libvlc-dev` (Ubuntu 22.04),
  then libvlc.so.5*, libvlccore.so* and the full plugins/ tree are copied
  into vlc_libs/ and collected by PyInstaller (doremi-linux.spec). The
  concrete VLC build is recorded per CI run (`dpkg -l | grep vlc`,
  `ldconfig -p | grep vlc`). No VLC version is vendored in git.

Build baseline: Ubuntu 22.04 x86_64, glibc 2.35 (recorded per build via
`ldd --version`). Binaries carry that minimum glibc forward; newer distros
(glibc >= 2.35) are expected to run them, older ones are not supported.

   Upstream: https://www.videolan.org / https://code.videolan.org
   Files: vlc_libs/libvlc.so.5*, vlc_libs/libvlccore.so*, vlc_libs/plugins/**
   (Ubuntu libvlc5 + vlc-plugin-base builds; exact package versions in the
   per-build manifest, e.g. 3.0.x from Ubuntu 22.04 universe).
   License (libraries): GNU Lesser General Public License v2.1 or later
     (LGPL-2.1+). VideoLAN relicensed libVLC and libVLCCore from GPL to
     LGPL; press release: https://images.videolan.org/press/lgpl-libvlc.html
     ("libVLC and libVLCcore are now relicensed under the LGPL").
   License (plugins): MIXED. The VLC plugin tree contains modules under
     GPL-2.0-or-later (and some LGPL). The full plugins/ directory is
     shipped, so GPL-licensed code IS redistributed.
   What this portable does: ships the .so files + full plugin tree as
     received from the Ubuntu packages; includes this notice; the launcher
     (doremi.sh) and in-process setup (utils/vlc_check.py) pin the bundled
     copies via PYTHON_VLC_LIB_PATH / LD_LIBRARY_PATH / VLC_PLUGIN_PATH.
   Deliberately NOT bundled: glibc, GPU drivers and other host-specific
     system libraries — those always come from the host system.
   BLOCKED for public release: (a) bundle the LGPL-2.1 and GPL-2.0 license
     texts for VLC; (b) provide the required source offer / written offer
     for libVLC/libvlccore (and GPL plugins) — e.g. link + instructions to
     obtain the exact Ubuntu source packages matching the shipped build
     (`apt-get source libvlc5 vlc-plugin-base` for the recorded versions);
     (c) audit which plugins are actually loaded vs. shipped and either ship
     sources or trim the tree deliberately (do NOT silently drop plugins to
     dodge the audit). Doremi itself is GPL-3.0, which is compatible with
     LGPL-2.1+ and GPL-2.0+ plugin code as a combined work, but the source
     offer obligation remains.
